En este primer episodio comparto el contexto del proyecto: la idea detrás de SimplePodcast, por qué elegí Astro como framework y Keystatic como CMS, y los próximos temas que quiero cubrir en episodios futuros — desde el setup técnico hasta el deploy en Cloudflare Workers.

Mención rápida a las herramientas del stack:

* **Astro** para el frontend con output server-rendered.
* **Keystatic** como CMS embebido que escribe directo al repo.
* **Tailwind v4** para los estilos.
* **MDX** para el contenido largo de cada episodio.

Si te interesa el detrás de escena de un proyecto pequeño pero cuidado, este episodio es el punto de partida.
